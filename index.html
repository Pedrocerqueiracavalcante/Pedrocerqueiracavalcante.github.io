Sobre

Transformo ideias em soluções digitais.

Sou desenvolvedor web e construo o produto inteiro, e não apenas uma camada dele: a interface que o utilizador vê, a API que responde, o modelo de dados que guarda a informação e a publicação em produção.

Aprendo construindo sistemas que vão para o ar. Cada um dos projetos desta página nasceu de um problema concreto de um negócio — pedidos que se perdiam numa conversa, um evento que não tinha endereço próprio, uma lavandaria a receber encomendas por telefone. A minha experiência prática vem daí: escrever o código, publicá-lo, corrigi-lo com utilizadores reais a usar e continuar a mantê-lo.

Trabalho sobretudo com JavaScript, do frontend ao backend, e com a plataforma Cloudflare — Workers e Pages Functions no servidor, D1 e KV nos dados. Escrevo CSS à mão, com Grid, variáveis e clamp(), e uso frameworks apenas quando o projeto o justifica. Um dos sites que construí está sob a minha manutenção mensal, o que me obriga a escrever código que ainda faça sentido meses depois.

Projeto em destaque

Moreno Home

O projeto mais completo que construí: aplicação do hóspede, painel da equipa, API e base de dados.

Em produção Único desenvolvedor Acesso de demonstração

Atendimento digital de hóspedes num alojamento local. O hóspede lê o QR Code à entrada e pede limpeza, compras, comida, manutenção ou transporte em dois ou três passos. Do outro lado, a equipa vê os pedidos a chegar em tempo real, assume-os e conclui-os.

O que eu desenvolvi

  • Arquitetura completa — interface do hóspede, painel da equipa, API REST e modelo de dados com dez entidades relacionadas.
  • Entrada por QR Code que já identifica o quarto no próprio endereço, sem login nem formulário.
  • Pedido gravado antes do WhatsApp, com referência própria, para nenhum pedido se perder se a janela for bloqueada.
  • Painel em tempo real por Server-Sent Events, com histórico pesquisável e dois perfis de acesso.
  • Gerador de QR Code escrito de raiz, para respeitar uma Content-Security-Policy com script-src 'self' sem abrir exceções.

Arquitetura

Além da interface.

O caminho que um pedido percorre nos sistemas que construí — do toque do utilizador até à linha gravada na base de dados.

  1. Cliente Navegador ou aplicação instalada como PWA
  2. Web App HTML, CSS e JavaScript servidos na rede de edge
  3. API REST Endpoints próprios, JSON, CORS, sessões e permissões
  4. Cloudflare Workers · Pages Functions Código executado sem servidor, junto do utilizador
  5. Cloudflare KV · D1 Armazenamento NoSQL e base de dados relacional

Não desenho apenas o ecrã. Defino os endpoints, o formato das respostas, o que acontece quando uma chamada falha e onde a informação fica guardada. É essa camada que faz um pedido existir mesmo quando o utilizador fecha o separador.

Também é aqui que ligo serviços externos — pagamentos, envio de email e WhatsApp — através de webhooks e integrações autenticadas.

  • REST Endpoints próprios
  • JSON Contratos de dados
  • CORS Origens controladas
  • Serverless Workers e Functions
  • Dados KV e D1
  • Tempo real Server-Sent Events
