## Estrutura

```
.
├── index.html              página única
├── assets/
│   ├── css/styles.css      tokens de tema, layout e componentes
│   └── js/main.js          tema claro/escuro, revelação ao scroll
├── .nojekyll               desliga o processamento Jekyll do Pages
└── README.md
```

## Correr localmente

Não precisa de build. Basta servir a pasta:

```bash
python -m http.server 8000
# depois abrir http://localhost:8000
```
