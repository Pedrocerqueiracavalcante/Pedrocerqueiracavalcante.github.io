## Sobre este repositório

É o meu portfólio. Site estático em **HTML, CSS e JavaScript**, sem framework e sem
passo de build, publicado automaticamente pelo GitHub Pages a partir de `main`.

**Online em:** https://pedrocerqueiracavalcante.github.io/

### Estrutura

```
.
├── index.html                    página principal
├── projetos/
│   ├── moreno-home.html          páginas de detalhe, uma por projeto
│   ├── easy-clean.html
│   ├── old-school-music.html
│   └── menuz.html
├── assets/
│   ├── css/styles.css            tokens de tema, layout e componentes
│   ├── js/main.js                tema, menu e revelação ao scroll
│   └── img/                      capturas dos projetos
├── .nojekyll
└── README.md
```

### Decisões

- **Sem framework nem build.** O site é servido tal como está no repositório.
- **Tema claro e escuro** por tokens CSS, respeitando a preferência do sistema e
  guardando a escolha manual.
- **Acessibilidade**: HTML semântico, ligação para saltar conteúdo, foco visível,
  `prefers-reduced-motion` respeitado e menu operável por teclado.
- **SEO**: meta description, Open Graph, canonical e JSON-LD em todas as páginas.

### Correr localmente

```bash
python -m http.server 8000
# http://localhost:8000
```
